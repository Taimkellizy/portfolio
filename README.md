My personal website: a one-page portfolio plus a bilingual blog (English / Arabic).
Built as a design concept — dark, editorial, motion-heavy — where the site itself is
part of the work.

**Live:** https://taimkellizy-portfolio.vercel.app

## What's inside

- A single-page portfolio (hero, skills, case studies, experience, credentials, writing)
- A blog driven by markdown files — drop a post in `content/posts/`, it appears
- Full English + Arabic versions (LTR / RTL)
- Motion built with GSAP + Lenis, with a WebGL backdrop

Stack: Next.js, React, TypeScript. Deployed on Vercel.

## Running it locally

```
npm install
npm run dev
```

Then open http://localhost:3000. (`npm run build` for a production build.)

## Credits
